Tracks the Iran–Israel/Levant theatre from 15 sources, places stories on a map with a gazetteer, computes a 1–5 threat level that explains itself, and summarises stories in Turkish with a local language model. Data never leaves the machine.

The problem

An analyst at a crisis desk asks the same question every morning: “Has anything critical happened in the last hour, and where on the map is it concentrated?” News sites answer separately, chronologically and full of duplicates. A “threat level” gauge helps only if it can say why it is at that level; otherwise it breeds alarm fatigue or destroys trust.

What it does

  • Collection: 15 RSS feeds (Al Jazeera, BBC, Guardian, Haaretz, ISW and more), with an SSRF check, circuit breaker, retries and timeouts on every request.
  • Mapping: a gazetteer places each story at a point in the region; stories at the same point collapse into one marker with a count.
  • Explainable threat level: the 1–5 level is computed from critical events in the last 1/24 hours, the 6-hour trend, geographic spread and multi-source confirmation. The panel does not just say “3 · TENSION”; it states which measurement set it.
  • Turkish summaries, data stays local: a local model writes a neutral one-or-two-sentence Turkish summary per story. Output that fails the language check is discarded; if the model is off, the summary stays empty.
  • Counting is code’s job, wording is the model’s: “critical developments” and “trend” in the situation summary come from counts; the model only writes the story bullets.
  • Operator tools: manual markers and drawing, nuclear-site and air-defence layers, watch words, live streams, a command palette, a Markdown situation report and hot database backup.

Measurements

The struck-through value is what was found, the one beside it what was measured after the fix. Every number comes from the project’s own record.

How it was built with AI

  1. 1Design contract. DESIGN.md defines the brief (surgical, calm, tactical; no emoji), the token system and anti-template rules. Every UI round is verified at four screen widths.
  2. 2Model choice by measurement. Local summary models were compared on real stories: llama3.2:3b mixed English and Chinese words into Turkish; gemma3:4b produced clean Turkish in about 2 seconds.
  3. 3No blind trust in agent output. In an earlier round, an AI self-assessment had entered the repo titled “independent certificate”. The audit added a note at the top saying it is a self-assessment.

September 2026 audit

Locally, 231 + 55 tests were green; CI had been red for five weeks. Measuring it revealed:

  • Tests were deleting the live database’s backups. API tests wrote into the real backup directory; one more run and rotation would have deleted the operator’s only real backup. Tests moved to a temporary database, with a guard test.
  • RSS never fetched (0/15). The SSRF check and the request resolved the same host twice, and slow DNS stalled the thread pool. The check moved to connect time: 15/15 feeds, ~430 stories in 25 seconds.
  • False alarm. Events were dated by read time, so after a month offline the board opened at “5 · CRITICAL”. A camel-race story (“intercepted”) counted as a missile event. Three separate threat calculations were merged into one.
  • Fake AI summary. With no model running, five canned sentences were saved as the “AI summary”; removed.
  • Interface: the map layer was empty because it needed an API key, half the live streams were dead, and 71 emoji and 94 raw colour codes were punching holes in the design system.

Every fix came with a regression test. Before each push, the full CI was simulated in a clean node:22 container.

Takeaway

A monitoring tool’s most dangerous failure is not crashing but showing something wrong yet convincing: an empty feed, a stale alarm, a made-up “AI summary”. Leaving accuracy to counting and wording to the model is therefore a design decision.

Honest limits

What this project does not do, or has not proven yet.

  • A single-operator tool; no hosted demo.
  • The threat level derives from the news flow; it measures what is published, not the situation on the ground.
