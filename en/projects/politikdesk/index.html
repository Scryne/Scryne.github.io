PolitikDesk

A political intelligence desk that ties claims to evidence with deterministic rules

Collects the macro, legislative and political agenda from 101 sources, clusters stories into events, leaves every claim’s verification status to deterministic rules rather than AI, and drafts sourced editorial copy only for evidenced events.

The problem

For someone following the agenda, the problem is not access to information but knowing which of it is verified. One story in five newspapers looks like five sources, yet all belong to one media group. AI summarises well, but letting it decide what is true ties the whole system’s credibility to that day’s model guess.

What it does

Every five minutes a loop runs:

  1. Collect: central bank, statistics office, Official Gazette, parliament, court of accounts, news sites and X lists; SimHash deduplication.
  2. Cluster: stories are linked into events with local embeddings.
  3. Evidence: claims are tested against independent corroboration pools with rules R0–R8; without official data or a document a claim cannot become “verified”, however far it spreads.
  4. Draft: sourced drafts only for evidenced events; no number or quote absent from the evidence may enter, and there is no automatic publishing path.

Audit

A project recorded as “2,711 tests pass” had been red in CI for at least five weeks: the number was measured against a local database full of data, and the tests hit real sources and demanded a real API key. All made hermetic: 2,701 tests, 0 failures, ~50 seconds on an empty database with no secrets.
