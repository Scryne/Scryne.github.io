Collects the macro, legislative and political agenda from 101 sources, clusters stories into events, leaves every claim’s verification status to deterministic rules rather than AI, and drafts sourced editorial copy only for evidenced events.

The problem

For someone following the political and economic agenda, the problem is not access to information but knowing which information is verified. The same story in five newspapers looks like five sources, yet all belong to one media group. A viral claim may rest on no official document at all. AI is excellent at summarising this picture, but if it is allowed to decide whether a claim is true, the system’s whole credibility hangs on that day’s model guess.

So the product’s contract is one sentence: “AI does not speak for you; it follows the agenda for you so that you can speak better.”

What it does

Every five minutes a five-step loop runs:

  1. 1Collect: pulls from the central bank, statistics office, official gazette, parliament, the court of accounts, news sites and X lists with polite-bot rules (rate limits, robots.txt, backoff); deduplicates with SimHash.
  2. 2Cluster: links stories into events with local embeddings; numerical conflicts go to human review.
  3. 3Evidence: claims are tested against independent corroboration pools with rules R0–R8. Newspapers of one media group count as one source. Without official data or an institutional document, a claim cannot become “verified”, however far it spreads.
  4. 4Context: relates a new event to past promises, parliamentary votes, audit findings and the actors’ earlier statements.
  5. 5Draft: writes sourced drafts from four editorial angles, only for evidenced events. No number or quote absent from the evidence may enter a draft. There is no automatic publishing code path.

How it was built with AI

  1. 1The boundary is locked in code, not in words. The evidence engine being unable to import the LLM module is a CI step (check_architecture.py), and the checker itself is tested. If the model ever wrote code crossing that line, the build would break.
  2. 2Model choice by the project’s own benchmark. The LLM is chosen on a Turkish golden set by quote fidelity, schema compliance and the rate of out-of-evidence numbers in drafts.
  3. 3Durable context. CLAUDE.md holds non-negotiable constraints, DESIGN.md the design contract, design/decisions.md the reasoning behind every UI round.
  4. 4Visual verification loop. UI work is captured at four screen widths and closed only after horizontal overflow and console errors are measured.

September 2026 audit

A project recorded as “2,711 tests pass” had been red in CI for at least five weeks: the number was measured against a local database full of data. Tests hit real sources, demanded a real API key and crashed on an empty database. All made hermetic: 2,695 tests, 0 failures, 49 seconds on an empty database with no secrets. The dead LLM was replaced, and pd update was found never to call the official-indicator step, and fixed.

Takeaway

A test count proves nothing until you say where it was measured. Hermetic tests come before a green CI.

Honest limits

What this project does not do, or has not proven yet.

  • A single-user personal terminal; no hosted demo, private repository.
  • Operational gates (the 7-day review window) have not fully elapsed.
  • Screens showing real politicians’ names were deliberately left out of this portfolio.
