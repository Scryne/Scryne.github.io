FabrikaOS

Multi-tenant MES + ERP for manufacturing

Collects live production data (OEE, downtime, faults) from the shop floor and brings work orders, maintenance, stock, quality, safety, HR and commercial modules into one control room. Every factory lives isolated in its own database schema; modules are licensed one by one.

The problem

In a mid-sized factory, production data lives on paper by the machine, maintenance in a spreadsheet, stock in the ERP and quality in another file. A manager joins four tables to answer “why did OEE drop this week?”. FabrikaOS collapses this into one product: data flows in from the floor, and every module sees the same data.

What it does

  • Live OEE from the floor: an edge agent sends measurements over MQTT and stores-and-forwards when the link drops; the dashboard updates over WebSocket with no manual entry.
  • Structural isolation: every factory lives in its own PostgreSQL schema; a dedicated test family guards the rule.
  • Production to shipment: a work-order state machine, a bill of materials consumed from stock automatically, lots traced backwards and forwards.
  • Modules: maintenance, downtime + Pareto, stock and purchase approval, quality + CAPA, energy, safety, HR, CRM, contracts, document management.
  • Intelligence and SaaS: predictive maintenance, anomaly and OEE forecasts; plan × module entitlements, 2FA, OIDC SSO, an immutable audit log, data export and anonymisation.

Audit

Re-measured screen by screen: CI had been red for two months (tests hit a real object store), every visit to the anomaly screen notified every manager, the WebSocket token leaked into logs, every page overflowed on mobile. All fixed; where possible, locked with a regression test.

Design

A “control room”: anthracite, blue only for actions, colour only for status. Each menu section carries a line colour from industrial pipe colour codes; numbers are set in tabular mono so columns align.

Limits

  • A product development study with no live customer; no hosted demo, private repository.
  • GA operations sprints (observability, disaster recovery, UAT) and the supply-chain module were not built.
  • Real PLC integration on the edge is a skeleton; tests use a simulator.
  • Playwright end-to-end tests are not in CI (they need a running stack).
